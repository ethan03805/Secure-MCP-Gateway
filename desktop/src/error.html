  • Restart the Gateway from the menu bar, then open the console again.
  • Check in Settings that the admin listener address is the one in your Gateway configuration ([admin_listener] address) and that the CA file is the installation's tls/ca.crt, or empty for the default.
  • After a certificate rotation, close this window and open the console again.
