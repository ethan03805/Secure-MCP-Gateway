The console's certificate was refused

The console's address did not present a certificate from this Gateway's certificate authority, so the console was not loaded. Nothing from that address was shown, and this window has no way to continue past this page (SR-2.8-5).

Why this happens

Another program may be using the console's address, or the Gateway's certificates were replaced.

What to do

  • Restart the Gateway from the menu bar, then open the console again.
  • Check in Settings that the admin listener address is the one in your Gateway configuration ([admin_listener] address) and that the CA file is the installation's tls/ca.crt, or empty for the default.
  • After a certificate rotation, close this window and open the console again.

The window title names the check that failed. If the error stays, copy that title into a bug report. The desktop guide, docs/desktop.md, explains this page under "Console window".
