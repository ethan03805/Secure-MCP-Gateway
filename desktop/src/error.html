The console was not opened

The admin listener did not present a certificate issued by this installation's Gateway CA for the configured address, or the CA file could not be read. The desktop application opens the console only over a connection it can verify, so nothing from that listener was shown and you cannot continue past this page.

What to check

  • The Gateway is running (tray icon) and the admin listener address in Settings is the one in your Gateway configuration ([admin_listener] address).
  • The CA file in Settings is the installation's tls/ca.crt. Leave it empty for the Standalone default.
  • After a CA rotation, close this window and open the console again from the tray.

The window title names the check that failed. See the desktop guide, docs/desktop.md, section "Console window".
