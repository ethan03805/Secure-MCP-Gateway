## Observations

- 28 of the 30 strings followed the guide as found. Two desktop strings did not, both in the first-run introduction, which every platform shows: the task "start it on this Mac" and the setup step "On a Mac the Gateway runs in the Standalone profile", shown on Linux and Windows as well, and on Linux also where setup offers the Enforced profile. That broke principle 3 (state security exactly) and FR-20.40 (no statement of protection that the installed profile does not provide). The same change that adds this record rewords them for every platform (`desktop/src/intro-steps.ts:35`, `desktop/src/intro-steps.ts:46`, and the client step at `desktop/src/intro-steps.ts:61`); the table shows the corrected strings.
- No sampled string uses a banned word, an exclamation mark, an emoji or an em dash, which agrees with `tools/uilint` passing at the commit.

## Deviations

- The inspection was made by an agent reading the extracted strings and their sources, not by a person reading the running interfaces.
- The desktop ten were chosen from user-facing files rather than by even spacing over every extracted desktop string, which falls mostly on internal error details.
