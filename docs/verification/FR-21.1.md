## Version refusal

`cmd/smcpctl.TestInstallWindowsVersionRefused` (run by the `go` job of every CI run, claim in the status data) lowers the reported build with the installer's test hook: build 22621 is refused with "build 22621 is not supported: the Gateway needs Windows 11 version 23H2 (build 22631)" and Windows Server build 17763 with "... the Gateway needs Windows Server 2022 (build 20348)", each with "nothing was changed" and no directory created; builds 22631, 26100 (client) and 20348, 26100 (server) are accepted. The rule is `internal/winsvc/winsvc.go:61-70`; the installer calls it before it creates anything (`cmd/smcpctl/install_winuser_test.go:194-221`).
