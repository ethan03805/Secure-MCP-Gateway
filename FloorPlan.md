# MCP Servers — FloorPlan

Updated: 2026-10-20 (phases 3 to 11: every element of release 1.x wired into `smcpd`, the hostile fixture suite, the console with every Appendix C role and the OpenAPI description, the acceptance, conformance and performance suites with Enforced results for every scenario and recorded reference hardware, the release pipeline with the Homebrew tap, its verification workflows, release provenance files and the SBOM license check, the Enforced profile installer, runbook execution records, the Real agents lockdown job, site chapters for status, install and agents, the user guide; releases v1.0.0, v1.1.0 and v1.2.0 published; for v1.3.0, the desktop application, the platform installers, the Windows port, the ContextForge Connector and the southbound Streamable HTTP transport built in part, with the pre-release v1.3.0-beta.1)

Scope: this repository (`Secure-MCP-Gateway`). This map covers every top-level path and the main subdirectories. Paths are relative to the repository root.
